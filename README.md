
# CampusNotes 📚

A community-driven academic resource platform
for departmental students.

## Features

- Semester-wise study materials
- Subject-based search
- Previous-year question papers
- PDF preview and downloads
- Student resource contributions
- Admin moderation dashboard
- Supabase authentication
- Responsive interface
- Dark mode

## Technology

- HTML5
- CSS3
- JavaScript
- Supabase
- GitHub Pages

## Installation

1. Clone this repository.

   git clone https://github.com/YOUR_USERNAME/CampusNotes.git

2. Open the project in VS Code.

3. Configure config.js with your Supabase
   project URL and publishable key.

4. Run schema.sql in Supabase SQL Editor.

5. Create a storage bucket named campusnotes-pdfs
   using the SQL setup.

6. Create your account and promote your account
   to admin using the SQL instructions.

7. Open index.html using a local development
   server such as VS Code Live Server.

## Deployment

1. Push the project to GitHub.
2. Open repository Settings.
3. Select Pages.
4. Set Source to GitHub Actions.
5. Push to the main branch.
6. Wait for deployment to complete.

## Demo Mode

Set DEMO_MODE to true in config.js
to explore the interface without a backend.

Demo submissions are local to the browser.
